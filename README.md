# Species Mission

This project is a simple educational game for primary school pupils.

Players match animals, plants, and trees to the correct European country on a map. The activity is designed to be easy to use in class, with:

- drag and drop or tap interaction
- simple English instructions
- hints for each species
- a final written worksheet
- a printable PDF-style export for classroom use

The goal is to help children learn about European species, geography, and nature protection in a playful way.
